# GeoGuessrV2
Predicting geo coordinates from an image. Training on a RTX-4070 and a custom dataset containing 100,000 images allowed me to get an average distance of roughly 2,000km. I think this method has potential when scaling up the compute, model and most importantly the dataset.
For this project I created the following [dataset](https://huggingface.co/datasets/deboradum/GeoCoordinates).
